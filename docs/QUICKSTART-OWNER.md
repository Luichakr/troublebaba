# Быстрый старт для владельца

## Что у тебя есть

- Полный сайт `troublebaba.com` (лендинг + 10 страниц рецептов + блог + free-recipe).
- 4 языковых PDF в приватном хранилище (uk/ru/en/pl), выдача только по подписанной ссылке.
- 9 языков интерфейса (uk/ru/pl/en/es/de/fr/it/pt).
- Всё что нужно чтобы продавать глобально: локальные валюты, юр-подтверждение, антибот, ограниченная выдача файлов.

## Что осталось сделать тебе — по важности

### 🔴 Обязательно, блокирует настоящие продажи

**Paddle KYC — активировать production.**

1. Заходишь `vendors.paddle.com` → аккаунт → **Business verification**.
2. Заполняешь: имя, страна, тип бизнеса (обычно **Individual** если без ФОП), ID (паспорт/права), банк для выплат, налоговая юрисдикция.
3. Ждёшь одобрения — до 2 рабочих дней.
4. После одобрения — пишешь агенту «Paddle одобрен, вот production API key» — он переключает `PADDLE_ENV=sandbox` → `production` в Cloudflare, обновляет ключ, и настоящие карты начинают работать.

Пока не сделано — сайт живой, но платежи не проходят (только тестовые карты `4242 4242 4242 4242`).

### 🟡 Легко и быстро (по 10 минут каждое)

- **Telegram-чат для покупателей.** Создаёшь закрытую группу в Telegram → копируешь invite-ссылку → отправляешь AI. Агент включит бонусный блок «Доступ у закритий Telegram-чат покупців» на сайте и в письме после оплаты.
- **2-3 скриншота Instagram.** Из твоего @troublebaba — комментарии/DM с добрыми словами (без имён/фамилий). AI поставит их как соц-доказ на главной. Это самое сильное что можно сделать для доверия без реальных отзывов.
- **Дата окончания скидки.** Сейчас `-33%` показывается вечно, а надо на конкретную дату (напр. «-33% до 15 августа»). Скажи агенту какую дату ставить.

### 🟢 Приятно, но не срочно

- **Прогнать реальную покупку** после Paddle KYC — купить с реальной карты, убедиться что письмо приходит, файл скачивается.
- **Проверить что письма не в спаме** на трёх разных ящиках (Gmail, Outlook, iCloud).

## Что делает AI-агент без тебя

Всё техническое:
- Правит код, тексты, дизайн.
- Пушит в GitHub (Cloudflare деплоит автоматически).
- Управляет файлами в R2 (заливка/удаление PDF).
- Меняет переменные окружения в Cloudflare.
- Перезапускает деплои.
- Читает логи функций.

Тебя AI спрашивает только когда **нужно твоё решение** (какую цену, какую фразу, какое фото) или **нужен твой пароль/личность** (Paddle KYC, банковские данные).

## Если что-то сломалось

1. Пиши AI-агенту в чат — опиши симптом («форма не отправляется», «письмо не пришло», «кнопка не работает»).
2. AI посмотрит логи (у него есть доступ к Cloudflare observability), найдёт причину, починит.
3. Если пропал доступ к Cloudflare/GitHub — новому AI-агенту нужно один раз пройти OAuth (`claude mcp login ...` + `wrangler login` в терминале) под твоим аккаунтом.
